# QuickTube Controls

A lightweight Chrome extension that brings quick-access video controls to YouTube.

## Why I Made This

YouTube's native controls require multiple clicks to change quality or playback speed. I wanted **instant access** to the features I use most—without navigating through menus every single time.

## What It Solves

- **Quality Selection** — Change video resolution in one click, right from the player controls
- **Speed Control** — Instantly adjust playback speed (0.25x to 2x)
- **Screenshot Capture** — Save any video frame as a PNG with automatic timestamped filename

## The Impact

✅ Faster workflow for content creators, students, and researchers  
✅ No more digging through YouTube's settings menu  
✅ Clean, native-looking UI that blends with YouTube  
✅ Zero data collection — runs entirely locally

## How to Install

1. Download or clone this repository
2. Open `chrome://extensions/` in Chrome
3. Enable **Developer mode** (top-right toggle)
4. Click **Load unpacked** and select the QuickTube folder
5. Go to any YouTube video — you'll see the new controls!
